=== webcpp 0.1.0

// tag::0.1.0[]
* Added Boost.Asio contexts and timers with browser event-loop suspension.
* Added configurable browser turns, defaulting to 100 ready handlers.
* Added Promise and DOM-event operations with cancellation and allocator support.
* Added browser socket adapters, retained resolver names and TLS settings.
* Added WASIp3 TCP, UDP, timers and experimental cooperative threads.
* Added Cobalt integration with browser scheduling and WASIp3 networking.
* Added optional source-built OpenSSL and replaceable embedded CA certificates.
* Fixed Cobalt TLS state/cancellation and TLS error equality across shared libraries.
* Fixed global configuration propagation and allocator routing for resolver inputs.
* Added Diataxis guides, compiled examples and MrDocs API reference.
// end::0.1.0[]
