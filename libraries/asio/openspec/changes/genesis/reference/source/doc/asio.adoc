= asio: Boost.Asio in the browser's event loop for {cpp}
:toc: left
:toclevels: 1
:idprefix:
:sectanchors:
:example-caption!:
:attribute-missing: warn

asio is Boost.Asio natively, and in the browser Boost.Asio's own
`io_context` suspended into the page's event loop, in {cpp}20, one of the
libraries of https://github.com/webcpporg/webcpp[webcpp]. A program written
against Boost.Asio, `main()` and `io_context::run()` included, runs
unchanged in a browser: compiled with Emscripten, asio adds only what Boost
lacks there, the configuration Asio needs to build, what wakes `run` from a
browser event, and a limit on the handlers one turn runs, so that the page
keeps rendering.

== Find your way through the guide

The guide follows https://diataxis.fr/[Diataxis]: choose a path for what
you need now. All paths share the compiled examples and generated API
reference on this page.

* *Complete a task:* <<asio-building,build and load a program>>,
  <<asio-run-configure,configure a turn limit>>,
  <<asio-timers-example,schedule and cancel timers>>, or
  <<asio-testing-application,test your application>>.
* *Understand the design:* read <<asio-overview>>, <<asio-run-turn>>,
  <<asio-browser>> and <<asio-allocation-runtime>>.
* *Look up a contract:* use <<asio-names>>, <<asio-guarantees>> and
  the generated <<reference,API reference>>.
